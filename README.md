# Stable-and-Fair-Platooning-Benefit-Allocation

This is the code for our work in the paper "Stable and Fair Benefit Allocation in Mixed-Energy Truck Platooning: A Coalitional Game Approach" submitted to Automatica, and revised in 2026. It includes the verification of the key theoretical results proposed in the paper and comparison with existing baselines.
